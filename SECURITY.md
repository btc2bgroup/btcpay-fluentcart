# Security Policy

## Supported versions

This plugin is pre-1.0 and only the latest released version receives security fixes.
Please upgrade to the newest release before reporting an issue.

| Version | Supported |
| ------- | --------- |
| 0.0.13  | ✅        |
| < 0.0.13 | ❌        |

## Reporting a vulnerability

**Please do not open a public GitHub issue for security problems.**
You can use our contactform for reporting, it's monitored daily:
https://btc2bgroup.com/contact

Please include in your message:
- affected plugin version, WordPress version, FluentCart version, and PHP version
- a description of the issue and its impact (e.g. forged payment confirmation, key disclosure)
- steps to reproduce, or a proof of concept
- any suggested fix

### What to expect

- Acknowledgement within 3 business days.
- An assessment and a plan (fix or explanation of why it isn't a vulnerability) within 14 days.
- A patch release and a published advisory once a fix is available. Reporters are credited
  unless they ask otherwise.

Please give us a reasonable window to ship a fix before disclosing publicly.
